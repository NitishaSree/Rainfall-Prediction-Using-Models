# 🌧️ Rainfall Prediction Using Machine Learning Models

## Overview
This project focuses on predicting rainfall using Machine Learning techniques by analyzing weather-related features such as temperature, humidity, wind speed, and atmospheric pressure. The project applies data analysis and classification models to identify patterns in historical weather data and predict the possibility of rainfall.

## What it does
- Cleans and preprocesses weather datasets
- Performs Exploratory Data Analysis (EDA)
- Analyzes relationships between weather conditions and rainfall
- Builds and compares Machine Learning classification models
- Predicts rainfall based on environmental factors
- Evaluates model performance using accuracy metrics

## What I learned
- Data cleaning and preprocessing techniques
- Handling missing weather data
- Exploratory Data Analysis (EDA)
- Feature engineering and data visualization
- Training and evaluating Machine Learning models
- Comparing classification algorithms
- Using Scikit-learn for predictive modeling
- Extracting insights from real-world weather datasets

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook
